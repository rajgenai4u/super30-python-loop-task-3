# Real-World Loop Challenges

This repository contains practical solutions to real-world data processing, string manipulation, and algorithmic problem-solving challenges using Python loops, as part of the **Super30 Python Series**.

---

## 📌 Objectives

- Apply `for` and `while` loops to solve practical data analysis tasks.
- Implement manual logic without relying on built-in helper functions (such as `sum()`, `max()`, `min()`, `len()`, or `Counter`).
- Master string manipulation, character frequency counting, pointer techniques, and nested control flow.
- Build interactive multi-step CLI utilities driven by infinite `while` loops.

---

## 💻 Implemented Challenges & Solutions

### 1. Financial Data Aggregation
- **Total Transaction Value:** Calculate total revenue across a list of transactions using loop accumulators (without `sum()`).
- **Peak & Minimum Values:** Identify the highest and lowest transaction amounts manually (without `max()` or `min()`).

### 2. Metrics & Grade Analytics
- **Average Calculation:** Compute average temperature values manually by tracking running sum and list length simultaneously, alongside concise built-in implementations.
- **Score Bucket Categorization:** Filter and count student performance metrics across multiple grade brackets (`90+`, `75–89`, `50–74`, and `<50`) using traditional `for` loops, list comprehensions, and `filter()` with `lambda`.

### 3. Security & Access Control
- **Login Retry System:** Interactive password authentication system featuring maximum attempt tracking (3 attempts max) and `while-else` safety locks.

### 4. Dictionary & Collection Filtering
- **Threshold Filtering:** Filter high-value product pricing from dictionary data structures based on customizable price conditions.

### 5. String Manipulation & Algorithms
- **Character Frequency Counter:** Measure frequency distributions of individual characters in custom strings without using `collections.Counter`.
- **Second-Largest Value Finder:** Single-pass algorithm to isolate the second distinct maximum value in unsorted arrays without using `.sort()`.
- **Two-Pointer Palindrome Checker:** Efficient string comparison evaluating character pairs from both boundaries toward the center using a dynamic `while` loop.

### 6. Interactive CLI Application
- **ATM Simulation:** Complete menu-driven CLI banking interface (Check Balance, Deposit, Withdraw, Exit) powered by an infinite `while` loop with input validation and positive float enforcement.
